# Experiment 9: Basic Dashboards in Tableau

## Aim
To combine multiple worksheets into one readable and interactive dashboard.

## Theory
A dashboard presents related views on one screen so users can compare performance quickly. A useful dashboard has a clear purpose, consistent titles, logical visual hierarchy, and only the filters needed for exploration. Typical components are a KPI, category comparison, regional contribution, trend view, legend, and filter.

## Algorithm
1. Connect to the sales dataset.
2. Create worksheets for Sales by Category, Sales by Region, and Sales versus Quantity.
3. Create a new dashboard.
4. Drag the worksheets into a balanced layout.
5. Add a Region filter and apply it to the relevant worksheets.
6. Add titles, legends, and a concise dashboard heading.
7. Test the filter and save the workbook.

## Result
A basic multi-view dashboard plan was created successfully.

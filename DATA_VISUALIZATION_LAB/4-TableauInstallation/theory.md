# Experiment 4: Introduction to Tableau and Installation

## Aim
To understand Tableau products, interface, data concepts, and workflow, and to install Tableau Public.

## Theory
Tableau is a visual analytics platform built around dimensions, measures, worksheets, dashboards, and stories. Dimensions describe categories, measures are numeric values that can be aggregated, and shelves such as Rows, Columns, Marks, and Filters control the view. Tableau Public is useful for learning and portfolio work, but published workbooks are public.

## Algorithm
1. Open the official Tableau Public download page.
2. Download the installer for the operating system.
3. Run the installer and complete the wizard.
4. Launch Tableau Public and sign in if publishing is required.
5. Create a blank workbook and identify the Data pane, shelves, Marks card, and Show Me panel.
6. Confirm the workspace is ready.

## Practical Program
This is a GUI experiment, so `program.md` is the execution record rather than source code.

## Result
Tableau Public was installed and its essential interface and data concepts were studied.

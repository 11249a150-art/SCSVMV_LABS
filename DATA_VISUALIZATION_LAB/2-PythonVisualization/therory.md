# Experiment 2: Basic Visualization in Python

## Aim
To create line, bar, pie, scatter, and histogram visualizations using Python and Matplotlib.

## Theory
A line chart communicates change across an ordered axis. A bar chart compares independent categories. A pie chart shows parts of a whole when the number of categories is small. A scatter plot displays the relationship between two numeric variables, while a histogram groups numeric observations into intervals called bins.

## Algorithm

2. Prepare a small dataset for each chart.
3. Select a suitable chart type.
4. Add titles, labels, legends, and grids where appropriate.
5. Save each figure and interpret the visible pattern.

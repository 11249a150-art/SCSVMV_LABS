# Experiment 1: Introduction to Various Data Visualization Tools

## Aim
To identify common visualization tools and verify the Python libraries used in this laboratory.

## Theory
Data visualization converts structured data into graphical form so that trends, comparisons, distributions, and relationships can be understood quickly. Pandas prepares tabular data, Matplotlib creates foundational static charts, Seaborn supports statistical graphics, and Plotly creates interactive visualizations. The correct chart should be chosen according to the question being asked.

## Uses
- Explore large datasets.
- Detect trends, outliers, and relationships.
- Communicate analytical results.
- Support data-driven decisions.

## Algorithm
1. Import Matplotlib, Seaborn, Plotly, and Pandas.
2. Read the version of each package.
3. Display a labelled version report.
4. Confirm that the environment is ready for visualization.

## Program Explanation
`program.py` uses `importlib.metadata` to report installed versions and gives a clear status when a package is unavailable.

## Result
The visualization environment was inspected and the available library versions were reported successfully.

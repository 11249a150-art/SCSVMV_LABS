# Experiment 7: Creating Scatter Plot Maps in Tableau

## Aim
To create a scatter plot from two measures and prepare geographical fields for map-based analysis.

## Theory
A scatter plot places one numeric measure on each axis and reveals association, clusters, and unusual observations. Tableau recognizes geographic roles such as City, State, and Country and can place those fields on a map. A useful workflow begins with the scatter plot, then adds location to Detail or switches to a map view.

## Algorithm
1. Connect Tableau to `sales_map_data.csv`.
2. Place Sales on Columns and Quantity on Rows.
3. Select Scatter Plot from Show Me.
4. Add City to Detail and Region to Color.
5. Assign the geographic role to City if necessary.
6. Open a map view and compare regional patterns.

## Result
A Sales-versus-Quantity scatter plot and a geographical analysis workflow were completed.
